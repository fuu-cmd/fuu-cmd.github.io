05. Moderation and message deletion

Anti-scam checks messages and attachments according to configuration and bot permissions. Manual scanning reads accessible channel history. #scanspam, or /scanspam with action mulai, scans the server and directly deletes messages containing images that match references. The dashboard review scan does not delete until selected findings are confirmed.

Reference matching does not prove a message is a scam or guarantee detection of every photo of a person. False matches are possible. YORR cannot restore deleted messages. Administrators must understand this behavior before enabling automatic deletion or starting a scan.
