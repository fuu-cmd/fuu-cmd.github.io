03. Pemisahan guild dan akses

Riwayat dan fakta memori AI menggunakan scope guild serta User ID. Scope DM terpisah. Data lama yang belum mempunyai scope ditempatkan dalam karantina dan tidak otomatis dipakai sebagai konteks guild aktif.

Dashboard memeriksa izin pengelolaan server dan keanggotaan bot sebelum menyediakan data server. Fitur owner dan UC96 dibatasi sesuai hak akses. Data fitur khusus dikelola dalam cakupan fitur tersebut; pemisahan memori AI tidak berarti semua jenis berkas atau integrasi memakai format penyimpanan yang sama.

Operator yang memiliki akses administratif ke komputer penyimpanan dapat mengakses data lokal. Pemisahan scope membatasi penggunaan antar-guild oleh aplikasi; ini bukan jaminan bahwa data terenkripsi terhadap operator.

04. Pihak penerima dan layanan eksternal

Discord menyediakan data akun/server dan menerima pesan atau tindakan bot. Anggota server dapat melihat hasil fitur sesuai izin channel. Lihat Privacy Policy Discord.

OpenAI API digunakan untuk respons dan fitur AI. Permintaan dapat memuat pesan, nama dalam konteks, riwayat yang relevan, fakta memori yang digunakan, serta prompt gambar. Pemrosesan provider mengikuti dokumentasi kontrol data OpenAI API dan pengaturan akun operator. Konten API tidak dipakai untuk pelatihan secara default kecuali pelanggan memilih membagikannya; kebijakan ini tidak menyatakan pengaturan opt-in khusus akun operator atau menjamin Zero Data Retention.

Tavily menerima kueri ketika fitur pencarian web digunakan. Kata dalam kueri dapat berasal dari permintaan pengguna. Lihat Privacy Policy Tavily.

YouTube/Google, TikTok, dan PUBG dapat dihubungi ketika monitoring atau fitur game terkait diaktifkan, menggunakan identitas sumber/player dan parameter permintaan yang diperlukan. Laporan melalui email Gmail dan DM Discord juga diproses oleh platform komunikasi tersebut. Lihat kebijakan Google dan kebijakan pada platform yang digunakan.

GitHub menghosting halaman kebijakan publik. File data bot, kredensial, memori, dan database tidak termasuk situs statis yang disiapkan.

Provider dapat memproses data di negara berbeda sesuai layanan, kontrak dan pengaturan mereka. YORR tidak menjanjikan lokasi pemrosesan provider tertentu, retensi nol, atau bahwa penghapusan lokal menghapus salinan provider. Kontak operator bila kamu membutuhkan penjelasan terkait data yang dikirim.

06. Laporan dan penghapusan

Permintaan akses, koreksi, atau penghapusan hanya disampaikan melalui laporan kepada owner: Discord @shyn13_ atau email fuu.gamersindo@gmail.com. Tidak tersedia command Discord untuk mengajukan atau mengecek penghapusan.

Owner memverifikasi identitas dan kewenangan pemohon serta data/guild yang dimaksud. Admin server dapat meminta penanganan data server yang berhak dikelolanya; permintaan tersebut tidak otomatis memberi akses ke data pengguna atau guild lain. Verifikasi tidak dilakukan dengan meminta password, bot token, OAuth secret, atau API key.

Target penghapusan data asli yang menjadi cakupan permintaan adalah paling lambat 7 hari sejak laporan diterima oleh owner, termasuk waktu verifikasi. Tenggat tidak dihitung ulang dari waktu pencatatan. Permintaan yang sudah diverifikasi dicatat pada alat internal; worker menghapus memori AI aktif pada siklus berikutnya saat online.

Backup terkait dibersihkan 30 hari setelah data asli dihapus. Data di backup masih dapat tersimpan dalam masa tunggu ini. Data AI baru dari penggunaan setelah penghapusan mempunyai masa retensi tersendiri.

Alat otomatis mencakup berkas riwayat/fakta AI dan backup yang dikelola bot. Konfigurasi/audit, turnamen, log, backup eksternal, komunikasi email/DM, dan provider membutuhkan penanganan terpisah oleh operator/platform. Owner akan menjelaskan cakupan, status, dan keterbatasan permintaan kepada pemohon. Penghapusan lokal tidak otomatis menghapus pesan Discord atau salinan pihak lain; hak pengguna yang berlaku tetap dihormati.

07. Keamanan dan pilihan pengguna

Dashboard menggunakan state pada OAuth2, pemeriksaan izin server-side, proteksi CSRF untuk perubahan, serta cookie sesi HttpOnly dan SameSite. Cookie Secure digunakan saat dashboard berjalan melalui HTTPS. Bot token, secret OAuth, dan API key merupakan konfigurasi server melalui environment; tidak dibagikan sebagai konfigurasi situs publik.

Operator menggunakan akses pada mesin lokal untuk mengelola penyimpanan dan pemulihan. Tidak ada jaminan keamanan absolut atau klaim bahwa seluruh file/backup terenkripsi saat tersimpan. Laporkan dugaan akses tidak sah kepada operator.

Kamu dapat berhenti menggunakan fitur AI atau meminta penghapusan. Admin dapat mematikan fitur dan mencabut bot. Hindari memasukkan informasi sensitif yang tidak diperlukan. Pilihan ini tidak dengan sendirinya menghapus data yang sudah ada; gunakan alur laporan di atas.
